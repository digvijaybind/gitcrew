# Ship

Read the git history (`git log --oneline`), `PRD.md`, and `TASKS.md`. Write
`README.md` (pitch, run instructions, what was built, the crew, status) and
`CHANGELOG.md` (honest `Added`/`Fixed` bullets under `## [1.0.0]`). Cut tag
`v1.0.0`. Final commit `ship: v1.0.0`.
